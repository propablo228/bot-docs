Политика конфиденциальности

Последнее обновление: февраль 2025 г.

Настоящая политика конфиденциальности описывает, какие данные собирает и использует бот все знама величественные при работе на серверах Discord.

1. Данные, которые мы собираем

Для корректной работы бот может обрабатывать следующие данные:

  • Discord User ID (идентификатор пользователя) — для выполнения команд модерации
  • Discord Server ID (идентификатор сервера) — для хранения настроек сервера
  • Discord Channel ID (идентификатор канала) — для настройки функций бота
  • Содержимое сообщений — только в момент выполнения команды, не хранится

2. Как мы используем данные

Собранные данные используются исключительно для:

  • Выполнения команд модерации на сервере
  • Хранения настроек и конфигурации бота на конкретном сервере
  • Ведения журнала действий модерации (варны, муты, баны) в пределах сервера

3. Хранение данных

Мы храним минимально необходимое количество данных. Данные пользователей не передаются третьим лицам и не используются в коммерческих целях. После удаления бота с сервера данные этого сервера могут быть удалены по запросу.

4. Передача данных третьим лицам

Мы не продаём, не сдаём в аренду и не передаём ваши данные третьим лицам. Бот взаимодействует только с API Discord в соответствии с их политикой конфиденциальности.

5. Безопасность

Мы принимаем разумные меры для защиты данных от несанкционированного доступа. Тем не менее, ни одна система не является абсолютно защищённой.

6. Права пользователей

Вы имеете право запросить удаление ваших данных. Для этого свяжитесь с нами через Discord сервер или по контактным данным ниже.

7. Контакты

По вопросам конфиденциальности обращайтесь к администрации бота через Discord.
